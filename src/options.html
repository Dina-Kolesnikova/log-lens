⌕ Log Lens

Auto-run sites — Log Lens will automatically enhance JSON on pages matching these URL patterns. On any other page, use the toolbar button.

    A pattern is scheme://host/path and * is a wildcard anywhere in it: https://logs.example.com/*, *://*.example.com/*, https://*-staging.example.com/logs/*. End the path with * to cover everything under it.
    Chrome can only grant permission per domain, so a pattern with a wildcard inside the host is granted one level wider — the line under the input always shows what Chrome will be asked for. Log Lens then auto-runs only on URLs matching the pattern you typed. Everything is processed locally and nothing is sent anywhere.

    Appearance

    Colors and font size apply everywhere Log Lens renders. Changes save automatically and sync with your Chrome profile.
